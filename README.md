# JetTagging

This project was developed throughout the course Machine Learning and Artificial Intelligence in Physics at the Institute of Physics of the University of São Paulo, 2024.

The training of the algorithms can be found in the folder ML/.
The main classes developed in this project can be found in the src/ folder. 

In particular, the following classes are included:

JetImage – used to create the jet representation via images;

BackwardElimination – implementation of the Backward Elimination algorithm;

EdgeConvLayer – implementation of the convolution layer for the Particle Cloud. This can be found inside the folder src/ParticleNet.
